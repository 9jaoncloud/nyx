Rigorous cross-language evaluation isolating compiler codegen and memory models using identical allocation paradigms (Bumpalo, Arenas, SwissTables, and CLBG standards).

Methodology Note: This suite establishes equal-control baselines. Rather than comparing bulk memory allocation against naive reallocation loops, all tested languages are configured with identical capacity-preallocation, arena strategies, or SIMD layouts.

🔬 Experiment 1: 10,000,000 Contiguous Allocations (Arena / Bump Control)

Measures allocation throughput for 10M structured records. In Rust, C, and C++, arena allocators are explicitly used to ensure identical $O(1)$ pointer-bump mechanics.
