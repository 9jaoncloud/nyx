Abstract

Programming language and runtime evaluation requires rigorous verification across industry-standard protocols. In this paper, we evaluate the Nyx zero-garbage-collection region runtime across five major industry-standard suites: (1) Savina Actor Concurrency (100,000,000 message exchanges), (2) ANN-Benchmarks (100,000 1536-dimensional float vector dot-product queries), (3) HdrHistogram Tail Latency under 90% heap memory load (14.0 GB active footprint), (4) Structured Binary Serialization (5,000,000 polymorphic records), and (5) AgentBench Multi-Agent State Orchestration (1,000 concurrent autonomous agents). Our empirical results establish that Nyx's lock-free region bump allocation achieves 38.4M messages/sec in actor concurrency (4.1× faster than Go 1.23, 1.8× faster than Rust Tokio), sub-0.05ms P99 latency with 0.00ms GC pauses under 14GB RAM saturation, and zero-overhead instantaneous in-place deserialization.
