🚀 Quick Start: Code & Run in 60 Seconds

1 Extract Archive

Extract the downloaded zip or tar.gz archive to any directory (e.g. C:\nyx or ~/.nyx). Run install.bat or install.sh to automatically configure your PATH.

2 Write Your Code

Create a simple source file named app.nyx using any editor (VS Code, Vim, or Notepad).

3 Compile & Run

Execute immediately in memory with zero GC pauses via Region JIT or compile to a standalone native binary.

Terminal Workflow (Windows, Linux, macOS) Zero Dependencies 
# Verify installation and toolchain target
$ nyx --version
nyx v0.28.0-prod (target: x86_64-pc-windows-gnu, llvm 18.1.0, region-inference, mobile-sdk, tri-mode-android)

# Scaffold a high-velocity mobile app or web microservice
$ nyx new my_app --template=mobile-app

# Run immediately with instant Region JIT (sub-millisecond launch)
$ nyx run app.nyx

# Compile to standalone hardened native binary with LLVM
$ nyx build app.nyx -o my_binary
