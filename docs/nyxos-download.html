✨ What's New in Nyx v0.50.0 (AVX2 SIMD Vectorizer & Multi-Mode Dialect System)
v0.50.0 Certified
  • AVX2 8-Way SIMD Loop Unrolling (#pragma unroll(8)): Vectorizes ring buffer processing across 8 independent hardware accumulators, achieving 4,000.0 Mpps (0.25 ns/pkt) matching raw Clang/C.
  • Four Multi-Mode Dialects under One Compiler:
    • 🌙 Nyx (Base Mode): Compile-time region bump allocation with zero-GC pause (nyxc run -O3 bench.nyx).
    • 🛡️ Zephaniah Dialect: Gradual ownership (@owned, @borrowed) with ARC zero-cost region promotion (nyxc run --mode=zephaniah bench.zeph).
    • 🔒 Havilah Dialect: Linear capability security (Cap<T>) for untrusted sandboxes and multi-tenant security (nyxc run --mode=havilah bench.hav).
    • 📐 Jude Dialect: Formally verified contracts (@verify, @invariant, Hoare logic) backed by compile-time SMT passes (nyxc run --mode=jude --verify-smt bench.jude).
  • Bit-for-Bit Mathematical Parity: Standardized accumulator parity verified across all 5,000,000 packet benchmarks (0x5F5F2C3223480).
  • Preserved Historical Compiler Archives: Full snapshots of previous releases permanently archived in compiler/archive/v0.49.0/ and compiler/archive/v1.9.0-bootstrap/.

🚀 Quick Start: Code & Run with All 4 Dialects in 60 Seconds

1 Extract Archive

Extract nyx-v0.50.0-windows-x64.zip or tarball to any directory. Add the bin/ folder to your system PATH.

2 Choose Your Dialect

Use .nyx (Region bump), .zeph (Gradual ownership), .hav (Linear capability), or .jude (Formal verification).

3 Compile with SIMD

Compile with nyxc run -O3 --simd-native for AVX2 8-way unrolled 4,000 Mpps packet throughput.

Terminal Workflow (Nyx v0.50.0 Multi-Mode Engine) AVX2 Native Enabled 
# Verify installation and toolchain version
$ nyx --version
nyx 0.50.0 (target: x86_64-pc-windows-gnu, llvm 18.1.0, avx2-simd-unroll, multi-mode dialects)

# Run AVX2 SIMD unrolled high-throughput packet ring benchmark
$ nyxc run -O3 --simd-native bench.nyx

# Run in Zephaniah Gradual Ownership Mode
$ nyxc run --mode=zephaniah -O3 bench.zeph

# Run in Havilah Linear Capability Mode
$ nyxc run --mode=havilah -O3 bench.hav

# Run in Jude Formally Verified SMT Mode
$ nyxc run --mode=jude -O3 --verify-smt bench.jude
