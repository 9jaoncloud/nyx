🏗️ The 4 Architectural Pillars of Nyx Intention OS

1. Pen-Tablet & Stylus Spatial Flow

When a stylus hovers or touches the glass, the OS bypasses the traditional start menu. An interactive Radial Action Halo blooms contextually with instant tools: lasso, OCR equation solver, voice annotator, and magnetic shape generator.

2. Ephemeral Bento Action Pods

Instead of launching a 200MB office suite for a 10-second calculation, the OS generates lightweight, disposable Micro-Pods that evaluate SIMD formulas or edit text in-place, then collapse cleanly without leaving orphaned processes.

3. Contextual On-Device SLM Ingestion

An on-device small language model running on the NPU monitors active context (clipboard, active document, selected nodes) and pre-populates intention cards with actionable next steps before the user even types.

4. 120 FPS Spring-Damped Physics

All card transitions, stacking animations, and expansions are computed using zero-GC spring-damper equations executed directly on the GPU compositor at locked 120 Hz with sub-millisecond input-to-photon latency.
