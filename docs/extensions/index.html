The 3 Companion Extension Dialects

Select any companion dialect below to explore its syntax, formal semantics, compiler flags, and industrial use cases:

⚡
.zeph • --mode=gradual

Zephaniah

Ergonomics & Gradual Ownership: Designed for rapid development and application code where strict lifetime annotations are burdensome. Uses progressive strictness and automatic ARC fallback.

  • Zero Lifetime Annotations: Write high-level script-like code with C performance.
  • Gradual Borrow Checker: Enforces borrow checking only where declared.
  • Ideal For: Web services, UI controllers, scripts, and high-level business logic.
Explore Zephaniah →
🛡️
.hav • --mode=capability

Havilah

Linear Capability = Ownership: Minimalist architectural security where resources are linear capability tokens. Dropping the capability immediately and deterministically frees the underlying resource.

  • Linear Type System: Capabilities cannot be duplicated, leaked, or forged.
  • Drop = Deallocate: No garbage collection and no region tracking overhead.
  • Ideal For: Microkernel drivers, hardware peripheral sandboxes, multi-tenant cloud.
Explore Havilah →
📐
.jude • --verify

Jude

SMT Formal Mathematical Verification: Embeds first-order logic pre/post condition contracts (@verify) directly into systems code, discharging proof obligations to Z3/CVC5 solvers.

  • Machine-Checked Proofs: Zero runtime assertion cost; verified at compile-time.
  • Cryptographic Certificates: Emits standalone .jude.cert audit artifacts.
  • Ideal For: Avionics flight control, medical devices, cryptography, defense systems.
