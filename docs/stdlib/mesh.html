@nyx/mesh — Kubernetes Client & Cloud Service Mesh Data Plane

A cloud-native framework delivering direct Kubernetes CRD orchestration, zero-overhead sidecar data planes, transparent mutual TLS (mTLS) certificate rotation, and distributed load balancing.

☸️ Direct Kubernetes API

Native client watching Pods, Deployments, and Custom Resource Definitions (CRDs) with WebSocket chunk streaming.

🛡️ Automatic mTLS 1.3

Zero-trust sidecar encryption with automatic SPIFFE/SPIRE certificate rotation and hardware key isolation.

⚡ Microsecond Hop Latency

Sub-microsecond request routing without Envoy proxy memory bloat (operates at <3MB RAM per proxy node).

🔀 Active Circuit Breaking

Real-time outlier detection, adaptive retry policies, and automated failover traffic shifting.

2. Comprehensive Practical Examples

☸️ Example A: Building a Real-Time Kubernetes Pod Auto-Scaler

Connect to the in-cluster Kubernetes API server, watch pod health status events, and trigger scaling actions. 

use @nyx/mesh;
use @nyx/http;

fn main() {
    // 1. Connect to Kubernetes API using in-cluster ServiceAccount token
    let k8s = mesh::connect_in_cluster();

    println("Connected to Kubernetes cluster: {k8s.cluster_name}");

    // 2. Query active pods in production namespace
    let pods = mesh::list_pods(&k8s, "production");
    println("Found {pods.len()} active pods running.");

    for p in pods {
        println(" - Pod: {p.name} | Status: {p.phase} | IP: {p.pod_ip}");
        if p.restart_count > 5 {
            println("   ⚠️ Alert: Pod {p.name} has restarted {p.restart_count} times!");
        }
    }
}
🛡️ Example B: Spawning a Sub-Millisecond Sidecar Proxy with mTLS

Intercept inbound HTTP requests, enforce TLS 1.3 encryption, and route to backend microservices with automatic circuit breaking. 

use @nyx/mesh;

fn start_proxy() {
    let sidecar = mesh::create_sidecar(
        8080, // Ingress Port
        "http://127.0.0.1:3000" // Upstream service
    );

    println("🛡️ Zero-Trust mTLS Mesh Proxy active on :8080 -> :3000");
    mesh::run_sidecar(&sidecar);
}

3. Function Reference

Signature Parameters Return Description
mesh::connect_in_cluster() void K8sClient Initializes authenticated Kubernetes client from /var/run/secrets/kubernetes.io/serviceaccount/.
mesh::list_pods(client: ref K8sClient, namespace: str) client: ref K8sClient, namespace: str [PodInfo] Queries Kubernetes API and deserializes pod metadata into structured region records.
mesh::create_sidecar(port: u16, upstream: str) port: u16, upstream: str MeshProxy Spawns a high-throughput async reverse proxy with mTLS encryption and active health checks.
