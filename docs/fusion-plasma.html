1. The Grad-Shafranov Equilibrium Equation

The 2D axisymmetric equilibrium of a magnetically confined plasma in a Tokamak is governed by the non-linear Grad-Shafranov partial differential equation:

\[\Delta^* \psi = -\mu_0 R^2 p'(\psi) - F F'(\psi)\] \[\text{where } \Delta^* = R \frac{\partial}{\partial R} \left( \frac{1}{R} \frac{\partial \psi}{\partial R} \right) + \frac{\partial^2 \psi}{\partial Z^2}\]

Here \(\psi\) is the poloidal magnetic flux function, \(p\) is the kinetic plasma pressure profile, \(F = R B_{\text{toroidal}}\) is the poloidal current function, and \(\mu_0 = 4\pi \times 10^{-7}\text{ H/m}\).

2. 10 kHz Real-Time Control Loop

The @nyx/fusion package executes within a strict 100 µs time budget with \(O(1)\) stack bump region resets (std.core.arena). Mirnov magnetic probe fluctuations and Rogowski coil measurements are ingested directly over memory-mapped DMA: 

import std.physics.mhd_tokamak;
import std.core.arena;

pub fn main() {
    let cfg = TokamakConfig {
        major_radius_m: 6.2,           // ITER-class major radius (6.2m)
        minor_radius_m: 2.0,           // Plasma minor radius (2.0m)
        toroidal_field_t: 5.3,         // Toroidal magnetic field (5.3 Tesla)
        target_plasma_current_ma: 15.0,// Target current (15.0 MA)
        elongation_kappa: 1.85,
        triangularity_delta: 0.45,
        num_pf_coils: 8,
        num_magnetic_probes: 64,
    };

    let mut controller = TokamakPlasmaController::new(cfg);
    let mut arena = Arena::new(1024 * 1024);

    // 10,000 Hz Hard Real-Time Control Loop
    loop {
        let watermark = arena.mark();
        let telemetry = ingest_mirnov_telemetry(&mut arena);
        
        let cmd = controller.step_10khz_cycle(&telemetry, &mut arena);
        dispatch_pf_coil_inverters(&cmd);
        
        // O(1) instantaneous bump rewind: 0.00 ms GC pause guarantee
        arena.rewind(watermark);
    }
}
