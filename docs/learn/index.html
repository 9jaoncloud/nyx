Lesson 1: Zero-GC Region Lifetimes & Arena Allocation

Unlike languages that rely on tracing garbage collectors (Go, Java, Python, Dart) which incur unpredictable 15ms–40ms stop-the-world pauses, Nyx allocates memory into deterministic, lexically inferred regions.

Key Architectural Principle:

When a function enters a scope, Nyx's compiler infers its lifetime boundary. Values that do not escape the scope are allocated on the stack or in bump-allocated region arenas. When the scope exits, memory is reclaimed in a single instruction with zero runtime fragmentation.

fn compute_metrics(samples: &Vec<f64>) -> f64 {
    let mut total: f64 = 0.0;
    for val in samples.iter() {
        total = total + val;
    }
    total / (samples.len() as f64)
}
