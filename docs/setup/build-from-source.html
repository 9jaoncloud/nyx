Building from Source

Full Build Instructions

# Clone the repository
git clone https://github.com/9jaoncloud/nyx
cd nyx

# Build everything in one shot
chmod +x scripts/bootstrap.sh scripts/build-all.sh
./scripts/build-all.sh

What Gets Built

  1. nyx-bootstrap/ — Rust compiler (cargo build --release)
  2. nyxc/ — Self-hosted Nyx compiler (compiled by Phase 1)
  3. std/ — Standard library (.nyx modules)
  4. nyx-cli/ — Package manager + build system
  5. web-runtime/ — WASM JavaScript bridge
