1. The Region-Based Execution Model

Every function in Nyx automatically instantiates a thread-local bump arena. Objects that do not escape the function scope are allocated contiguously and dropped in O(1) bulk time upon return:

import std.core;
import std.json;

fn process_payload(raw_json: String) -> Int {
    // Allocated inside the function's local region frame:
    let parsed = json::parse(raw_json);
    let mut total_score = 0;
    
    for item in parsed.items {
        total_score = total_score + item.score;
    }
    
    // parsed and all intermediate nodes are dropped in O(1) bulk time here!
    total_score
}

2. Escape Analysis Topology (The 5 Scenarios)

When an object must outlive its creating frame, Nyx's O(V+E) intra-procedural escape engine classifies it into one of five distinct promotion topologies:

Escape Pattern Runtime Action Overhead
1. Frame-Bound Local Allocated in local region frame arena 0.00 ms (Zero-GC, O(1) drop)
2. Return Value Handoff Shallow copy moved to caller's parent region Zero heap allocation
3. Struct Field Insertion Promoted into the target host struct's region Region unification
4. Closure Environment Capture Captured into heap-allocated Env_fn struct Local ARC pointer (rt_arc_t)
5. Cross-Thread Channel Send Promoted to thread-safe atomic reference count Atomic ARC (rt_arc_atomic_t)

3. Multi-Dialect Memory Architectures

In addition to Nyx Base region arenas, the sovereign extension dialects provide specialized memory substrates tailored for extreme systems, bare-metal hardware, and formal mathematical safety:

DIALECT: ZEPHANIAH (.zeph)

Lockless Atomics & ARC

Provides explicit reference tracking with compile-time ownership blame and zero-pause atomic cascades for high-throughput concurrency.

import std.sync;

@owned
fn dispatch_task(payload: Arc<TaskData>) {
    // Atomic refcount inc/dec with lockless CAS
    let worker = thread::spawn(move || {
        payload.execute();
    });
}
DIALECT: HAVILAH (.hav)

Linear Capabilities & Zero-Copy I/O

Enforces affine single-use capability tokens for memory-mapped I/O, device registers, and zero-copy DMA buffers without double-spending.

import std.mmio;

linear struct DmaToken { cap_id: u32 }

fn transmit_packet(consume token: DmaToken, buf: &[u8]) {
    // Token is consumed; compile error if reused
    mmio::dma_write(token.cap_id, buf);
}
DIALECT: JUDE (.jude)

SMT-Verified Invariant Regions

Formally verifies lifetime region lattices (R_parent ⊃ R_child) using Z3 theorem provers at compile time with 0 runtime bytes.

import std.smt;

region R_Sensor;
region R_Global;

// SMT Prover checks: R_Global contains R_Sensor
fn sample_telemetry<'R_Sensor>(s: &'R_Sensor Sensor) -> Telemetry {
    s.read_calibrated()
}

6. Real-Time Hard Assertion: @must_region

For high-frequency trading engines, audio DSP pipelines, robotics control loops, and avionics flight modules, Nyx provides the @must_region (or #![deny(heap_escape)]) pragma. If any variable in an annotated scope escapes to heap or Atomic ARC, the compiler produces a hard build error:

import std.core;

@must_region
fn audio_dsp_kernel(samples: &[f32; 1024]) -> [f32; 512] {
    // The compiler enforces that ALL operations in this block
    // execute strictly in stack region frames with 0.00 ms GC pauses.
    let mut fft_bins: [f32; 512] = [0.0; 512];
    for i in 0..512 {
        fft_bins[i] = samples[i * 2] * 0.707;
    }
    fft_bins
}
