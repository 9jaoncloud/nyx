Empirical Benchmark Methodology & 15-Point Specification

Nyx Systems Architecture Group • Published: August 2026 • Status: Open Verification
Methodology Abstract & Reproducibility Commitment

Benchmark credibility requires total hardware transparency, exact compiler versions and optimization flags, standardized warmup protocols, variance bounds (Mean ± σ), and publicly available source code. This document publishes the complete 15-point empirical protocol used across all Nyx benchmark suites, detailing physical CPU specifications, clock rates, cache hierarchies, and step-by-step instructions to reproduce every experiment on clean hardware.

Independent Replication Policy: All benchmarks are measured under controlled hardware conditions on physical silicon (see Hardware Specification below). All test harnesses, raw CSV data, and reproduction scripts are published openly under MIT license to enable peer review and independent third-party verification.

1. The 15 Academic Reproducibility Data Points

Every benchmark result in the Nyx literature adheres to the 15 reproducibility standards established by computer systems research:

  • ✔
    B1 — CPU Model & Clock: Intel Core i7-6700HQ @ 2.60 GHz (Skylake, 4 physical cores / 8 threads, 3.50 GHz turbo, 6 MB L3 cache). Tested on real hardware, not emulated VMs.
  • ✔
    B2 — Compiler Versions: Nyx: nyxc 0.29.0 (LLVM 18 LTO) • Rust: rustc 1.97.0 • GCC: GCC 14.2.0 • Node.js: Node 22.4.0 (V8 12.7) • Python: Python 3.13.0 • PHP: PHP 8.3.6.
  • ✔
    B3 — Compiler Optimization Flags: Nyx: -O3 --lto --target-cpu=native • Rust: -C opt-level=3 -C lto=fat -C target-cpu=native • C: -O3 -march=native -flto. All languages compiled to native machine instructions.
  • ✔
    B4 — Benchmark Source Code: 100% open source and published at docs/benchmark-code.html and in the public repository github.com/9jaoncloud/nyxos/benchmark.
  • ✔
    B5 — Standardized Workload Definitions:
    • Minimal Startup: Entry point execution time with zero-op main.
    • Sequential Alloc: 8,388,608 × 20-byte struct allocations in memory.
    • Random PRNG Alloc: 8,388,608 allocations with Xorshift64 stride access (eliminates CPU cache prefetcher bias).
    • Hash Map: 1,000,000 string key → u64 value insertions and lookups.
    • JSON Parse: 631 KB twitter.json parsed 100 times.
    • N-Body: 50,000 gravitational orbital simulation steps across 5 celestial bodies.
    • Matrix GEMM: 512×512 double-precision matrix multiplication across 10 iterations.
  • ✔
    B6 — Warm-Up Protocol: 1 unmeasured warm-up iteration preceding all timing to ensure instruction cache warming and page table mapping.
  • ✔
    B7 — Iteration Count: 5 measured iterations per test. Reported metrics represent the mathematical Mean (μ) across runs.
  • ✔
    B8 — Variance & Error Bars: All tables report Mean ± σ sample standard deviation (e.g. Nyx Random Alloc: 12.70 ms ± 0.18 ms).
  • ✔
    B9 — Memory Peak RSS: Peak resident set size tracked via OS memory management counters during full execution lifecycle.
  • ✔
    B10 — Allocation Counter: Exact count of heap/region allocations logged via allocator instrumentation hooks.
  • ✔
    B11 — Single-Thread Baseline: Allocation, JSON, and N-Body workloads are strictly single-threaded to isolate language runtime efficiency.
  • ✔
    B12 — Matched-Algorithm Control: Hash Map, GEMM, and JSON tests use identical hashing algorithms (FxHash), Robin Hood probing, and Snappy/ZSTD codecs.
  • ✔
    B13 — Standalone Binary Footprint: Nyx hello-world = 34.2 KB; HTTP web engine = 187 KB; full Unikernel = 4.8 MB.
  • ✔
    B14 — Zero-GC Verification: Hardware stop-the-world pause latency is measured and verified at 0.00 ms via Region Bump pointers.
  • ✔
    B15 — Multi-Core Concurrency Scaling: Lockless SPSC ring buffers evaluated across 1, 2, 4, 8 cores demonstrating 42ns inter-thread latency.

3. Step-by-Step Reproduction Guide

Run the complete automated benchmark suite on your own machine in 4 simple terminal commands:

# Step 1: Clone the public benchmark repository
git clone https://github.com/9jaoncloud/nyxos.git
cd nyxos/benchmark

# Step 2: Download Nyx Compiler (nyxc) from official downloads portal
# Windows: https://nyx.9jaoncloud.com.ng/downloads/nyx-v0.29.0-windows-x64.zip
# Linux:   https://nyx.9jaoncloud.com.ng/downloads/nyx-v0.29.0-linux-x64.tar.gz

# Step 3: Run the automated cross-language benchmark suite (5 runs, 1 warmup)
python run_benchmarks.py --all --iterations 5 --warmup 1 --output results.csv

# Step 4: Generate terminal & markdown summary report
python run_benchmarks.py --report results.csv
